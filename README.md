# A New Chapter Begins 🌺

An animated Bengali Pattachitra-inspired housewarming invitation and RSVP site, hosted with GitHub Pages.

**Date:** Saturday, November 7, 2026, dinner at 6:00 PM (Mountain Time).

**Venue:** 1295 W Giantsbane Dr, Meridian, ID 83642.

**GitHub Pages:** https://prathiksha11.github.io/-housewarming-rsvp/

GitHub Pages settings: **Settings → Pages → Deploy from a branch → main → /(root)**.

**RSVP submissions:** The site intentionally keeps submission disabled until a Formspree endpoint is configured in `config.js`. A static GitHub Pages website cannot store RSVP responses by itself. Do not publish Formspree secrets; its public form endpoint is safe to use in client-side HTML.

**Privacy:** The street address is publicly visible in this repository and to visitors of the site. Search indexing is discouraged, but the event is not access controlled.
